# Knowledge Engineering

[Autonomous Trailer](Autonomous_Trailer.ipynb) is the notebook for ICS 3202 Practical Exercise 4. It represents towns and directed roads as a knowledge base and uses Dijkstra's algorithm to find the shortest mapped route from Nairobi CBD to Kisumu Town.

Open the notebook on GitHub to read the worked example, or open it in Jupyter and run the cells from top to bottom. The example uses road distances stored in the notebook and does not need a live routing API.
